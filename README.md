# warsaw Fans Control

开启 80% 充电保护后，即使有线充电已经暂停，系统仍可能让风扇按极速充电场景运行。此模块能识别停充状态，退出该场景的散热请求。模块还支持息屏散热、按应用调速、狂暴模式、转速上限和实时测速，系统设置与控制中心共用同一风扇模式。

目前仅在一台 REDMI K90 Ultra（`warsaw`）上实测正常。测试时使用 HyperOS `OS4.0.8.0.XHPCNXM`，「电量和性能」版本为 `4.2.00`（40200）。

## 安装和使用

从 v0.4.3 可直接覆盖安装。若从 v0.4.2 或更早版本换装，先记下应用规则和转速上限，再到 LSPosed 停用旧包 `dev.k90fan.control`。Android 将新版识别为独立应用，旧包私有配置需要在新版重新设置。使用自定义转速时，还需在 SukiSU 为新包重新授予 Root。

1. 从 LSPosed 仓库或下方发布页下载并安装模块 APK。[下载最新版本](https://github.com/Xposed-Modules-Repo/io.github.sonnetoend.warsawfan/releases/latest)
2. 在 LSPosed 启用新包 `io.github.sonnetoend.warsawfan`，勾选「设置」`com.android.settings`、「电量和性能」`com.miui.powerkeeper` 和「系统界面」`com.android.systemui`。
3. 重启手机，打开系统原来的风扇设置页。
4. 保留「极速充电时启用」，在电池设置中选择 80% 充电保护。新增的「80% 停充时退出极速充电散热」默认开启。

从 v0.4.4 起，模块会在设置、电量服务和系统界面中分别检查所需的风扇接口。各进程的接口匹配后才启用对应功能。

## 风扇模式

在系统风扇设置的「风扇模式」或控制中心风扇磁贴的详情面板选择模式。初次安装和从 v0.3 升级时沿用原先的系统模式。

- **狂暴模式**在当前散热范围内请求原厂 4 档，实测设备上的目标为 19,800 rpm。选择「部分场景」时，只有系统判定为散热场景才启动。已设定的最高档位或自定义转速上限继续生效。
- **按应用自定义**会在设置页显示「应用配置」。点应用卡片右侧可选择「智能调频」「静谧模式」「高速强冷」「狂暴模式」或「关闭风扇」。静谧、高速、狂暴分别请求原厂 1、2、4 档。未配置的应用使用原厂智能温控。选回「智能调频」可清除该应用的固定档位。规则随前台应用切换。旧版已保存的 3 档规则显示为「原厂 3 档」，可改选其他模式。
- **息屏时允许风扇继续运行**是独立开关，默认关闭。开启后，锁屏时仍按场景和档位散热。关闭总开关、离开散热场景或触发原厂录音、通话停转条件时，风扇仍可停转。

回到任一原厂模式即可退出狂暴或按应用调速。应用规则会保留，供下次启用。

「应用配置」支持按名称和包名搜索。右上角可以调整排序或显示系统应用。列表适配深浅色和全面屏手势，应用图标从本机读取。

## 转速上限

打开「风扇转速上限」选择调节方式。

- **跟随系统**是新安装的默认值。退出自定义时还原驱动的原始转速表，原厂负责启停和选择档位。80% 停充修正可独立开关。
- **原厂 1 至 4 档**限制允许的最高档位，实测设备上依次对应 12,000、14,000、16,000 和 19,800 rpm。页面从本机设备树读取各档目标，无法读取时只显示档位。升级会沿用 v0.2 已保存的档位。
- **自定义**打开 HyperOS 的数字滚轮，在 12,000 至 19,800 rpm 之间每格调整 100 rpm。应用后可点「自定义目标转速」再次编辑。首次使用前，在 SukiSU 中向「warsaw Fans Control」授予 Root。实测使用 Haruhi `6.6.142-android15-8-4k-Haruhi-26w37f` 内核。自定义转速会在加载内置驱动前核对设备、内核版本、内核类型信息和风扇驱动标识。高于上限的档位使用新的目标，较低档位和停转仍由原厂控制。重启后，PowerKeeper 加载模块时会重新应用已保存的上限。

本机设备树 `/sys/firmware/devicetree/base/soc/xiaomi_fan/duty_speed_map` 中的占空比和目标 rpm 依次为 `(0,0) (51,12000) (65,14000) (73,16000) (98,19800)`。页面的「实时转速」读取 `real_speed`。实机内核日志记录过 20,416 和 20,457 rpm。19,800 rpm 表示四档控制目标，测速值可以超过它。

## 充电场景

PowerKeeper 的 `FanStateHandler` 初始化时读取 `IMiCharge.getQuickChargeType()`，随后接收 `miui.intent.action.ACTION_QUICK_CHARGE_TYPE`。原厂风扇把类型编号 ≥ 3 视为极速充电。电池广播中的电量和插电类型用于记录。风扇的最终档位还取决于场景、模式与温度。

有线极速充电、80% 保护和停充修正均开启时，模块检查 `smart_chg` 的保护位。保护位有效且驱动上报 `buck eff_client:soc_limit 0` 时，立即退出极速充电散热。保持插电时，驱动也可能上报 `buck eff_client:online 0`。如果电量为 79% 或 80%，模块还会读取 Android 的电池端净电流。电流绝对值不超过 100 mA 时退出充电散热，已退出时容许最多 200 mA 的波动。这两个阈值由模块设定。在这个分支中，超过 200 mA、离开 79%–80% 区间或读数不可用时，会恢复原厂判断。

确认停充时，模块仅在本次风扇策略计算中将极速充电标志置为假。电池事件、快充事件和设置变更会触发重新判断，有线极速充电等条件满足期间每 5 秒复查。充电控制仍由系统负责。

在这台 REDMI K90 Ultra 上，插电 100% 时读到快充类型 1、风扇 0 rpm。开启 80% 保护后，`smart_chg` 从 0 变为 16，停充原因从 `term_recharge` 变为 `soc_limit`。另一次在 79% 的实测中，原厂仍报告快充类型 4 和 `Charging`，保护位为 16，驱动上报 `online 0`，电池端电流为 0–7 mA。v0.3.2 当时曾进入风扇 1 档。

在相同的 79% 插电状态下，用原厂固定一档对照 v0.3.3 的修正开关。关闭修正时实测 11,055 rpm，开启修正后目标档位和实测转速均为 0。测试期间保留了同一充电器和 80% 保护设置。
